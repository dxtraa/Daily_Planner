      📖 How to import into Google Calendar
      1. Click the button above → file classes.ics akan ter-download
      2. Buka calendar.google.com
      3. Klik ⚙️ Settings (kanan atas)
      4. Pilih tab Import & Export
      5. Klik Select file from your computer → pilih file tadi
      6. Pilih calendar tujuan → klik Import
      7. Selesai! Kelas kamu muncul sebagai event mingguan 🎉
